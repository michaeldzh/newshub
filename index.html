4. arXiv 发布 Speculative Macro Commit 加速工具使用 Agent

来源：arXiv · 2026-09-04 · 原文

正文：研究人员在 arXiv 发表论文，提出 Speculative Macro Commit（SMC）运行时机制，用于加速工具使用型 LLM Agent。传统 Agent 在串行 action-observation 循环中，每次工具调用、环境转换和观察都会延迟后续决策。SMC 采用双层 Agent 架构：大型权威 actor 模型负责宏观规划，小型执行模型负责快速试错。通过推测性提交，执行模型可并行尝试多个工具调用路径，再由权威模型验证最优结果。实验显示，SMC 在复杂工具链任务中将端到端延迟降低 40%，同时保持 95% 以上的任务成功率。该研究为解决 Agent 推理效率瓶颈提供了新思路，对自动化工作流和代码生成场景具有直接应用价值。
